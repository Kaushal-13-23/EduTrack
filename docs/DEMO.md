# USIAMS Demonstration Checklist (9 Steps)

**Prerequisites:** Apache and MySQL are running, `sql/usiams.sql` has been imported into `usiams_db`, and the app is open at `http://localhost/usiams/`.

| Step | Action / Click Path | Sample Input / Test Action | Expected Result |
| --- | --- | --- | --- |
| **1. Splash Login Page** | Open `http://localhost/usiams/` in browser | Inspect page & submit empty form | Login card (`index.php`) loads; empty submit is blocked by JS with inline `.error` messages beside `Username` and `Password`. |
| **2. User Registration (Sign Up)** | Click **Sign Up** link → `signup.php` | Full Name: `Demo Admin`, Username: `demo_admin`, Email: `demo@example.edu`, Password/Confirm: `pass123` → click **Sign Up** | Redirects to `index.php` with green success message (`Account created successfully. Please log in.`); `users` stores a `$2y$` bcrypt hash. |
| **3. Invalid & Valid Login** | On `index.php`, enter `demo_admin` + wrong password → **Login**; then enter `demo_admin` + `pass123` → **Login** | Wrong password first, then valid password | Wrong password shows generic `"Invalid username or password."` without revealing which field failed; valid login redirects to `dashboard.php` greeting `demo_admin`. |
| **4. Add Student & Validation** | Click **Add Student** in navbar → `add_student.php` | Test invalid email/9-digit phone (`blur`/`submit`), then enter `REG2026010`, `Meera Krishnan`, `BTech IT`, `4`, `meera@example.edu`, `9876543210` → click **Save** | Invalid inputs are blocked with inline `.error` text; valid input saves to MySQL, regenerates `students.xml`, and redirects to `view_students.php` with green flash message. |
| **5. List & Search Students** | On `view_students.php`, inspect table, then use search bar | Search `Meera`, click **Search**; then click **Clear**; also try `REG2026001` | Table lists rows ordered by `reg_no`; search filters accurately via prepared `SQL LIKE` query; **Clear** restores full list. |
| **6. Edit Student** | Click **Edit** on `REG2026010` row → `edit_student.php?reg_no=REG2026010` | Verify `reg_no` is read-only; change Course to `MTech AI` and Semester to `6` → click **Update** | Redirects to `view_students.php` showing green flash message and updated values in both the table and MySQL `students`. |
| **7. Delete Student (Cancel & Confirm)** | On `view_students.php`, click **Delete** on `REG2026010` | Click **Cancel** in `confirm()` dialog first; click **Delete** again and click **OK** | Cancel keeps row intact; Confirm submits hidden POST form with CSRF token to `delete_student.php`, removes `REG2026010` from MySQL, and updates `students.xml`. |
| **8. View XML Records & Raw XML** | Click **View XML Records** in navbar or `view_students.php` (`xml_view.php`), then open `http://localhost/usiams/students.xml` | Inspect record count, table, and raw XML | `xml_view.php` shows total record count and escaped table matching MySQL; `students.xml` renders well-formed UTF-8 XML (`<students>/<student>`). |
| **9. Logout & Session Guard** | Click **Logout** in navbar (`logout.php`), then press browser **Back** and **Refresh** (or visit `dashboard.php`) | Navigate back to `dashboard.php` after logout | Redirects to `index.php`; protected pages send `Cache-Control: no-store` and cannot be reopened without logging in again. |
